# 天文計算

実装は [src/astro.hpp](../src/astro.hpp) / [src/astro.cpp](../src/astro.cpp)、テストは [tests/astro_test.cpp](../tests/astro_test.cpp)。
主な参考文献は Jean Meeus『Astronomical Algorithms』第 2 版（以下 Meeus）。

## 1. 全体の流れ

```
星表 (J2000.0 の赤経 α・赤緯 δ)
   │  単位ベクトル化（起動時に 1 回）
   ▼
J2000 赤道座標ベクトル ──[歳差 P(t)]──▶ 当日の平均赤道座標 ──[恒星時・緯度 H(t)]──▶ 地平座標
                                                                                 │ 大気差・減光（GPU）
                                                                                 ▼
                                                                         投影して画面へ（rendering.md）
```

毎フレーム CPU で `M = H(t) · P(t)` を計算して GPU に渡す。星ごとの計算は頂点シェーダで `h = M · v` を行うだけ。

## 2. 座標系の約束

| 座標系 | x | y | z |
|---|---|---|---|
| 赤道座標 | 春分点の方向（α = 0h） | α = 6h | 天の北極 |
| 地平座標 | 北 | 東 | 天頂 |

どちらも右手系。方位角は **北 = 0°、東 = 90°** の向き（北から東回り）、高度は地平線から上が正。

赤経・赤緯から単位ベクトルへの変換：

```
v = (cos δ cos α,  cos δ sin α,  sin δ)
```

## 3. 時刻

### シミュレーション時刻
[src/sim_clock.cpp](../src/sim_clock.cpp) は時刻を **Unix 時刻（UTC 秒）** の倍精度浮動小数で持つ。

- 実時間 dt ごとに `t += dt × 倍率 × (逆再生なら −1)`
- 地方時（JST）との変換はタイムゾーンのオフセットを足し引きするだけ（日本は夏時間がない）
- 日付 ↔ 通日の変換は Howard Hinnant の `days_from_civil` / `civil_from_days`（うるう年を含めて正確、ライブラリ不要）

### ユリウス日 (JD)

```
JD = Unix秒 / 86400 + 2440587.5
```

J2000.0 = 2000-01-01 12:00 UTC = JD 2451545.0（テストで確認済み）。

> **UT と TT について**：厳密には歳差・太陽位置には地球時 TT、恒星時には UT1 を使う。
> 差（ΔT ≈ 69 秒）による位置のずれは、歳差では無視できるほど小さく、太陽でも約 0.0008° なので、表示には影響しない。
> そのため UTC をそのまま両方に使っている。

## 4. 恒星時

グリニッジ平均恒星時（IAU 1982、Meeus 式 12.4）：

```
d = JD − 2451545.0,  T = d / 36525
GMST = 280.46061837° + 360.98564736629° × d + 0.000387933° T² − T³ / 38710000
```

地方恒星時 `LST = GMST + 経度（東経が正）`。大阪（135.52°E）は GMST より約 9 時間進む。

1 日で 360.9856° 回る（360° より約 1° 多い）のが、星が毎日約 4 分早く昇り、季節で見える星座が移る理由。
季節ジャンプで同じ 21 時に飛んでも空が違うのはこの項による。

## 5. 地平座標への変換

### 歳差 P(t)（IAU 1976、Meeus 21 章）
地球の自転軸は約 26,000 年周期で首振りしており、赤道座標の基準（春分点・天の北極）が年に約 50″ 動く。
星表の J2000 座標を当日の座標へ直す：

```
T = (JD − 2451545.0) / 36525
ζ = 2306.2181″T + 0.30188″T² + 0.017998″T³
z = 2306.2181″T + 1.09468″T² + 0.018203″T³
θ = 2004.3109″T − 0.42665″T² − 0.041833″T³

P = R_z(−z) · R_y(θ) · R_z(−ζ)
```

行列の各成分は `precessionFromJ2000()` に展開して書いている。

### 日周運動 H(t)
1. **z 軸まわりに LST だけ回す**：x 軸が子午線（時角 0）、y 軸が東を向く。
   ```
   R_z(LST) = | cos L   sin L   0 |
              | −sin L  cos L   0 |
              |   0       0     1 |
   ```
2. **緯度 φ で傾ける**：この座標系で北・東・天頂の単位ベクトルは
   `N = (−sin φ, 0, cos φ)`、`E = (0, 1, 0)`、`Z = (cos φ, 0, sin φ)`。
   これを行に並べた行列を掛けると、成分が (北, 東, 天頂) になる。
   ```
   | −sin φ  0  cos φ |
   |    0    1    0   |
   |  cos φ  0  sin φ |
   ```

地平ベクトル `h = (n, e, u)` から：

```
高度 = asin(u)
方位 = atan2(e, n)    （北 = 0°、東 = 90°）
```

確認（テスト）：赤緯 0° の星は南中時に高度 90° − φ・方位 180°、時角 −6h で高度 0°・方位 90°（真東）、天の北極の高度 = 緯度。

## 6. 大気差（屈折）

地平線付近ほど光が大気で曲がり、星が本来より高く見える。
真高度 h（度）から見かけの高度への補正（Sæmundsson 1986、気温 10℃・1010 hPa）：

```
R [分角] = 1.02 / tan(h + 10.3 / (h + 5.11))
```

地平線で約 29′、高度 45° で約 1′。GPU で星ごとに計算し、ベクトルの高度成分だけを持ち上げる（方位は変えない）。
真高度 −0.5° 程度の星まで地平線の上に見えるようになる。

## 7. 太陽の位置

空の明るさ（薄明）を決めるのに使う。Meeus 25 章の低精度式（誤差約 0.01°）：

```
L0 = 280.46646 + 36000.76983 T + 0.0003032 T²        平均黄経
M  = 357.52911 + 35999.05029 T − 0.0001537 T²        平均近点角
C  = (1.914602 − 0.004817 T − 0.000014 T²) sin M + (0.019993 − 0.000101 T) sin 2M + 0.000289 sin 3M
λ  = L0 + C − 0.00569 − 0.00478 sin Ω               視黄経（章動・光行差込み）
ε  = 23°26′21.448″ − 46.8150″ T + 0.00256° cos Ω       黄道傾斜角
α  = atan2(cos ε sin λ, cos λ),  δ = asin(sin ε sin λ)
```

太陽の座標は「日付の分点」なので、歳差 P を掛けずに H だけで地平座標に変換する。

## 8. 精度と今後

| 要素 | 現状 | 影響 |
|---|---|---|
| 歳差 | IAU 1976 | 2026 年で 0.36°。入れている |
| 章動 | 未実装 | 最大 約 20″（0.005°）。画面の 1px（魚眼で約 0.2°）よりずっと小さい |
| 年周光行差 | 未実装 | 最大 約 20″。同上 |
| 固有運動 | 未実装 | 速い星（バーナード星）でも 26 年で 0.08°。肉眼の星はほぼ影響なし |
| 大気差 | Sæmundsson | 地平線付近で約 0.5° の補正 |
| 月・惑星 | 未実装 | 次の段階で Astronomy Engine を導入予定（PLAN.md） |

1280×800 の魚眼では 1px が約 0.22°（180° / 800px）なので、表示上は ±0.01° の精度で十分。
