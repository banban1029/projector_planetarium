# 上映「大阪から阿智村へ ― 11 月の星空」ストーリー構成

| 項目 | 内容 |
|---|---|
| 長さ | 5 分 28 秒（328 秒、21 場面） |
| 日時 | **2026 年 11 月 2 日 22:00**（台本の `date`）。上映中に早送りして翌 3:00 まで |
| 場所 | 序章：大阪大学（吹田）→ 本編：**長野県阿智村**（ヘブンスそのはら、標高 1,400 m。台本の `location`） |
| 天気 | 再現しない（いつも晴天） |
| 音 | 字幕を読み上げるナレーション（Windows の日本語音声「Haruka」、少しゆっくり）と、ロマンチックなピアノの BGM。ナレーション中は BGM が自動で小さくなる |
| 見せるもの | 街と山の星空の違い、天の川、季節の目印（夏の大三角・秋の四辺形・カシオペヤ座・冬の大三角・冬のダイヤモンド）、北極星の見つけ方、土星、月・火星・木星の並び、おうし座流星群 |
| 再生 | `./show.sh`（MSYS2 Bash）／`.\show.ps1`（PowerShell）。台本は [autumn_2026.yaml](autumn_2026.yaml) |

日時と場所は台本の先頭（`date`・`location`）で決めている。ここを書き換えると全体の日時・場所が変わる。
ただし字幕の内容（どの星がどこに見えるか）はこの日時に合わせて書いているので、大きく変えたら字幕も見直す。

## 伝えたいこと

1. **街の明かりで星は見えなくなる**。同じ日・同じ時刻でも、場所が変われば星空はまったく違う。
2. **星空には季節の目印がある**。11 月の夜は、西に沈みかけた夏の大三角、頭の上に秋の四辺形、夜明け前には冬の星。季節の移り変わりが一晩で見える。
3. **見つけ方を知れば、本物の空でも探せる**。北極星の見つけ方、惑星の見分け方。

## 流れ

時刻は上映開始からの経過時間。「字幕」は画面下に出て、同じ文をナレーションが読む（読み方を変えたい場面は `narration` に別の文）。
語り口は、星の物語（七夕、アンドロメダ姫）を添えて、静かでロマンチックに。方位の文字（北・東・南・西）は最後まで出しておく。

## 台本（YAML）で使える項目

上映全体（`scenario:` の直下）：

| 項目 | 例 | 説明 |
|---|---|---|
| `title` | `"大阪から阿智村へ ― 11月の星空"` | 題名 |
| `date` | `"2026-11-02 22:00"` | 上映の日時（地方時）。場面の `time: start` / `time: "start+5:00"` で使う |
| `location` | `achi` | 本編の観測地（config の `locations` の id）。場面の `location: main` で使う |
| `audio.narration_dir` | `build/shows/autumn_2026` | ナレーションの WAV を置くフォルダ（`scripts/make_show_audio.ps1` が作る） |
| `audio.voice` / `audio.rate` | `"Microsoft Haruka Desktop"` / `0` | 読み上げの声と速さ（-10〜10） |
| `audio.narration_gain` | `5` | ナレーションを作るときに掛ける音量の倍率。割れないようリミッタ（[scripts/loudness.py](../scripts/loudness.py)）をかけるので、元の声が大きいと 2 倍ほどで頭打ちになる |
| `audio.bgm` / `audio.bgm_volume` | `build/shows/autumn_2026/bgm.wav` / `1.0` | BGM（`scripts/make_bgm.py` が作曲）と音量 |
| `audio.bgm_duck` | `0.15` | ナレーション中の BGM の音量（`bgm_volume` に掛ける割合。声を聞きやすくする） |

場面（`steps:` の各項目）：

| 項目 | 例 | 説明 |
|---|---|---|
| `duration_sec` | `15` | この場面の長さ [秒] |
| `time` / `location` / `speed` / `mode` | `start`、`main`、`600`、`real` | 日時・観測地・時間倍率・モード（書いたときだけ変わる） |
| `subtitle` | `"…\n…"` | 画面下の字幕（`\n` で改行）。ナレーションもこれを読む |
| `narration` | `"標高千四百メートル…"` | 字幕と違う読み方をさせたいとき（数字・記号の読み） |
| `asterisms` | `[summer_triangle]` | 季節の目印（`data/asterisms.csv` の id）。2 秒かけて線が順に結ばれ、名前が出る |

## 音の作り方

`show.sh` / `show.ps1` が自動で行う。手で作り直すときは：

```powershell
.\scripts\make_show_audio.ps1                 # 字幕が変わった場面だけ作り直す
.\scripts\make_show_audio.ps1 -Force          # すべて作り直す（BGM も）
```

- ナレーション：アプリが台本の読み上げ文を出し（`--dump-narration`）、Windows の音声合成（System.Speech）で場面ごとの WAV にする。
  場面の長さより長いナレーションがあると警告する。
- 音量：`narration_gain` が 1 でなければ、読み上げた WAV を [scripts/loudness.py](../scripts/loudness.py) で大きくする（割れないところで頭打ち）。
  文・声の速さ・倍率が前回と同じ場面は作り直さない。
- BGM：[scripts/make_bgm.py](../scripts/make_bgm.py) が作曲する（ヘ長調の 8 つの和音、64 秒の繰り返しのステレオ。
  やわらかいピアノの分散和音、オルゴールのような旋律、ストリングスのようなパッド、残響）。作るのに 1 分ほどかかる。
  `make_bgm.py` を書き換えると、次に音を作るときに BGM も作り直す。
  乱数の種を固定しているので、何度作っても同じ曲になる。
- 作った音は `build/shows/` に置く（git 管理外）。Windows の音声合成で作った音声は配布物に含めない。

## 確かめた事実（`--dump-positions --dump-names` で計算）

| 日時（阿智村） | 内容 |
|---|---|
| 11/2 22:00 | 土星は真南・高度 55°。夏の大三角は西の低い空（ベガ 18°、アルタイル 16°、デネブ 42°）。ペガススの四辺形はほぼ天頂（アルフェラッツ 78°）。カシオペヤ座は北の空・高度 65°。フォーマルハウトは南南西・高度 19°。月はまだ昇っていない |
| 11/2 22:00（大阪） | 土星は南・高度 56°、カペラは北東・高度 39°、ベガは西・高度 19°（街並みと光害で見えにくいので、序章ではカペラを指す） |
| 11/3 3:00 | 月（高度 36°）・火星（40°）・木星（34°）が東の空（方位 97〜99°）に 5° 以内で並ぶ。冬の大三角は南の高い空（ベテルギウス 62°、プロキオン 52°、シリウス 37°）。月明かりで空が少し明るい |

- おうし座流星群（南群・北群）は 10 月〜11 月に活動し、11 月上旬〜中旬に多い。数は少ないが明るい火球が多い。
  上映では見やすくするため、実際（1 時間に数個）より多く流している。
